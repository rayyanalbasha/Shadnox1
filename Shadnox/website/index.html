EVERYTHING IN ONE APP

Personalize it. Protect it.

Shadnox gives you the tools Windows and macOS hide behind menus, in one clean window.

◉

Private Screen

Dim your display with one shortcut so people nearby can't easily read it. Pick any key, set the strength, and cover every monitor.

☷

Desktop wallpaper

Choose any JPG, PNG or BMP and set it as your wallpaper in two clicks. Shadnox keeps its own copy, so it survives if the file moves.

▣

Lock screen

Use your own image on the Windows lock screen and restore the default whenever you like.

◐

Taskbar color

Pick any color with a built-in picker or a hex code. Reset to the original any time.

◌

Transparent taskbar

Remove the taskbar background for a clean, floating look that stays applied while Shadnox runs.

⌁

Lives in your tray

Close the window and Shadnox keeps working quietly. Start it with Windows so your setup is always back.

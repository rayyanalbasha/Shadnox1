Make your desktop truly yours.

iPhone / iPad

How to install

iOS does not permit a website to install an unsigned native IPA or create arbitrary app aliases.

Install on iPhone

  1. Open this website in Safari on your iPhone.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then tap Add.

This adds the Shadnox website as a Home Screen web app. It does not provide the native Private Screen overlay or permission to browse all installed iPhone apps. A native iOS app would require an Apple-signed build and distribution through Apple-supported methods.
